QDTech 小智 v1.8.19 SD 卡完整必需内容

本目录可直接整体复制到 FAT32 SD 卡根目录；合并复制即可，不要先删除原有个人照片、播客或存档。

本次整理内容：
1. 保留电影、书籍、播客、照片、FC 游戏和原有功能资源。
2. 更新日历星座、益智游戏馆、立体骰子和功德木鱼资源到当前版本。
3. 根目录提供 radio.json，供中文分类电台读取。
4. /roms/md/ 提供 53 款本机已有的中文精选 MD 游戏和 catalog.tsv 中文目录。
5. /retro-go/config/ 用于主系统与 MD 模拟器安全交接。
6. /retro-go/saves/md/ 用于自动存档；正常退出 MD 游戏后，存档会写入这里。

注意：
- v1.8.19 的普通 OTA 只更新主系统。板子必须做过一次“双模式完整刷机”，才具备 MD 模拟器分区。
- 不要把固件 App.bin、full.bin 或 mdemu.bin 放到 SD 卡；它们属于烧录文件，不是 SD 资源。
- 不要手动创建 md_handoff.json；选择游戏时主系统会自动生成。
- ROM 仅来自本机已有合集，仅供本机设备使用，不应上传 GitHub 或公开分发。
- 后续追加的街霸和快打旋风镜像声明六键；当前三键模拟可启动，但部分招式可能受限。
- 兼容性修订：马里奥使用4MB镜像版本；FIFA 98已由《FIFA国际足球》替代，原问题文件移至 `/roms/md-incompatible/`。
- 突然断电可能来不及保存；请使用游戏界面的退出功能返回主系统。
